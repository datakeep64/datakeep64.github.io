LLM-Based Media Assistant

A system using the OpenAI API to assist with media content workflows — summarisation, groundedness verification, sentiment analysis, headline rewriting, and content restructuring. The verifier directly tackles the biggest blocker to newsroom AI adoption: catching hallucinated facts before they reach print.

Python OpenAI API Prompt Engineering Faithfulness / NLI Output Validation NLP Streamlit

How It Works — in Plain English

Newsrooms want AI to help with routine writing jobs, like shortening an article, suggesting headlines or rewriting a story for a different reader. Doing the job is the easy part. The hard part is trusting the result: an AI can invent a fact, change a quote, slip in loaded words, or give a different answer every time you ask. This project does both halves: it gets an AI to do useful newsroom work, then checks that work before a person relies on it.

2 · Techniques used to get good answers from the AI

The way you ask an AI for something (the “prompt”) changes the answer a lot. Each task uses the technique that fits it best.

Give it a role and clear rules
e.g. “You are a professional news editor… do not add information that isn't in the source.” Each task has its own rules: summary lengths, restructure formats, audiences.
Make it show its evidence first
For sentiment, the AI has to quote the words that signal the tone before it picks a label. Reasoning first, answer second (“chain of thought”) gives fewer snap judgements.
Show one worked example
For headlines, the AI first sees one article with four ideal headlines (“one-shot” prompting). An example teaches the difference between the styles better than a description does.
Set the creativity level per task
Fact-checking runs with no randomness at all. Sentiment uses very little, and headlines use more, because there you want variety.
Ask for a fixed format
Sentiment, headlines and fact-checks come back as structured data (JSON) with named fields, not free text, so the app and other systems can use them directly.
Stream long outputs
Summaries and restructures appear word by word as they're written, so you don't wait for the whole thing.

Knowing when not to use AI. Two of the checks use no AI at all. Whether a quote is word for word is a plain text comparison, and a rule-based check is exact, free and the same every time. The neutrality check uses a curated word list, so every point it deducts traces to a specific word an editor can see and overrule. The AI is used only to suggest a more neutral rewrite.

3 · Making the output consistent

Asking for a fixed format isn't enough. The AI can still answer “positive” instead of “Positive”, write a confidence as “85%” or 0.85, leave out a headline, or give two identical headlines. And the same article can get “Neutral” one time and “Mixed” the next. Before these tools feed into the News Intelligence System, every answer goes through a checking layer:

AI answers
Same settings every time (a fixed random “seed”), so repeat runs are as similar as possible.
↓
Small slip → fix it quietly
“positive” → Positive · “85%” or 0.85 → 85 · stray quote marks and full stops removed
Real error → ask the AI to fix it
Unknown label, missing field, “short” headline over 8 words, or duplicate headlines: the exact error is sent back once. If it's still wrong, the app shows an error instead of passing on bad data.
↓
Extra guards
Key phrases the AI claims to quote are dropped if they don't actually appear in the article. Each label (Positive / Negative / Neutral / Mixed) now has a written definition, since “Neutral vs Mixed” was the most common flip.

4 · How it's evaluated

There are two kinds of checking: checks that score each output while the app runs, and automated tests that make sure the code behaves correctly.

Groundedness score · 0–100
The output is split into small, single-fact statements. Each one is checked against the source and marked Supported, Partial or Unsupported, with the exact source sentence as proof. The score is the share supported (Partial counts half). This follows published fact-checking methods (FActScore, SummaC).
Quote integrity
Every quote is marked Preserved, Altered (with a word-by-word comparison) or Fabricated, meaning there's no matching quote in the source.
Objectivity score · 0–100
Points are deducted for each loaded word across six categories. A suggested rewrite is re-scored, so you can see whether it actually improved.
Consistency · agreement rate
Optionally runs the sentiment analysis three times and reports how often the label matched (e.g. 3 of 3 = 100%).

Code tests: 42, all passing. They run without an API key or internet: the AI is replaced by a stand-in that gives pre-written answers, including deliberately broken ones. They cover the scoring maths, quote matching, the loaded-word list, and the fix-or-reject logic for bad AI answers.

Capabilities

Seven distinct tasks, each shaping model output — or guarding it — for a specific media use case.

📄

Article Summarisation

Condenses long-form news articles into concise summaries at configurable length, streamed word-by-word as the model generates.

✅

Groundedness Verification

Fact-checks a summary against its source using atomic-claim decomposition and textual entailment (the FActScore / SummaC approach). Flags hallucinations down to the individual claim, cites a verbatim supporting span for each verdict, and scores overall groundedness 0–100.

🔍

Quote Integrity

Checks that every direct quotation survived the transform byte-for-byte — flagging Preserved / Altered / Fabricated quotes with a word-level diff. Deliberately deterministic (exact + fuzzy string matching, no LLM), since verbatim-ness is a string property, not a probabilistic judgment.

⚖️

Neutrality Analysis

Flags loaded language — editorializing verbs, emotive framing, intensifiers, weasel attribution, agency-hiding passive — against a curated lexicon, with an objectivity score 0–100 and an optional LLM rewrite that's re-scored to show the gain. Transparent by design: every deduction traces to a specific word.

📊

Sentiment Analysis

Chain-of-thought classification — the model cites evidence from the text before labelling tone, against explicit label definitions. Output is schema-validated, key phrases are checked against the source, and an optional 3-run check reports label agreement.

✏️

Headline Rewriting

Generates four variants — neutral, SEO-optimised, explanatory, concise — using one-shot prompting. Each set is validated: all four present, distinct, concise ≤ 8 words; violations are sent back to the model for repair.

🔄

Content Restructuring

Transforms article structure — inverted pyramid → narrative, formal → plain English, news report → explainer, long-form → bullets — for general readers, experts, students or executives.
